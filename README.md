# SAT-KR Practice Generator

수능을 준비하는 학생을 위한 수능형 연습문제 생성 웹앱입니다. 현재는 국어 독서 한 과목을 먼저 깊게 만들고 있습니다.

## Features

- 국어 독서 지문 패턴 기반 새 문제 생성
- 난이도, 문항 유형, 출제 스타일 선택
- 내용 일치, 보기 적용, 추론 문항 지원
- 정답 및 해설 보기
- 브라우저 localStorage 기반 오답노트 저장

## Notes

이 앱은 실제 수능, 모의고사, EBS 교재 문항을 복제하지 않습니다. 국어 독서 문항에서 자주 보이는 지문 전개, 중심 주장, 대비 관점, 오답 선지 패턴을 규칙화해 새로운 연습문제를 생성하는 방향으로 설계되었습니다.
