# SAT-KR Practice Generator

수능을 준비하는 학생을 위한 수능형 연습문제 생성 웹앱입니다.

## Features

- 과목, 난이도, 문항 유형, 출제 스타일 선택
- 국어, 수학, 영어, 탐구 기반 샘플 문제 생성
- 정답 및 해설 보기
- 브라우저 localStorage 기반 오답노트 저장

## Notes

이 앱은 실제 수능, 모의고사, EBS 교재 문항을 복제하지 않습니다. 수능 및 EBS 학습 경향에서 볼 수 있는 문항 구조를 참고해 새로운 연습문제를 생성하는 방향으로 설계되었습니다.
